# Instruções para sessões de trabalho no EMERGENCE

- **Metodologia do programa:** ler e seguir [docs/program-methodology.md](docs/program-methodology.md). O modelo é o neurobiológico; divergir só com simplificação agnóstica de substrato justificada (mecanismo entendido, equivalência proposta, perdas declaradas).
- **Nomes, não códigos:** hipóteses, critérios, propostas, detectores, itens e algoritmos são citados por nome ([docs/nomenclature.md](docs/nomenclature.md)). Indicar se cada regra vem da literatura ou é proposta/inferência nossa.
- **Decisões científicas são do responsável:** mecanismo, critérios, limiares, equivalências. Não marcar itens do roteiro como concluídos sem validação.
- **Não alterar o repositório TEMPO** (paulosince/temporotopological-relations): só leitura.
- **Fontes:** nunca inventar; dizer o que foi lido (resumo ou texto integral) e a confiança de cada número.
- **Inovação:** a cada proposta, precedente ou evidência nova, atualizar [docs/innovation-tracking.md](docs/innovation-tracking.md) (o que existe, o que seria novo, o que falta para alegar).
