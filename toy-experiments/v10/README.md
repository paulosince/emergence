# EMERGENCE V0.10

[Executar interface](https://paulosince.github.io/emergence/toy-experiments/v10/) · [Pré-registro](./preregistration.md) · [Resultados](./results.md)

Experimento com meio 3D discreto de 12×8×6 células, propagação local por seis vizinhos, traços de atividade persistentes e plasticidade local. **Nenhum objeto Uint ou Upro é instanciado.** Células diferenciadas são candidatas de organização, não representações demonstradas. Interface com visualização sem contorno do cubo, controles e exportação CSV.
