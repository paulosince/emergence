# EMERGENCE V0.11

[Interface](https://paulosince.github.io/emergence/toy-experiments/v11/) · [Pré-registro](./preregistration.md) · [Resultados](./results.md)

Meio discreto tridimensional 12×8×6; propagação local em arestas adjacentes; memória escalar sem etiquetas de origem; condutância adaptativa e possível poda. Nenhuma Uint ou Upro é pré-instanciada. A visualização não desenha limites do cubo. As regiões acima de limiar são classificação externa, não unidades demonstradas. Código em ES Modules, sem build.
