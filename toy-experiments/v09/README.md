Sem dependências externas. Para execução local, servir a raiz do repositório por HTTP (`python -m http.server 8000`) e abrir `/toy-experiments/v09/`. A interface reutiliza o layout da V0.8: visualização 3D sem linhas do cubo, inspeção, controles e trilhas CSV.

**Aviso científico:** apesar da execução do núcleo, a geometria ainda não determina capturas nem a propagação real, conforme documentado em results.md. Não interpretar coincidências como representação.
